Dark mode templates

Four palettes for Tikorix dark mode. Each one is a complete token set plus a small mock of the pieces that go wrong today: a table row, the five stage pills and a modal with an input. Pick one and I'll roll it into the spec's §1.2.

What stays the same in every option
  • Only one family of tokens (--tk-*). The obsidian values are gone.
  • The lime accent (#d2e21a) does not change between themes.
  • Every stage pill reaches 4.5 : 1 against its own background (right-hand table on each card).
  • Every token has one definition in the :root block and one in the dark block. Nothing hard-coded in components.
